# Hi, I'm Zeli Su

I am a master's student in Electronic Information at Minzu University of China, working on multilingual large language models, low-resource languages, reinforcement learning for LLMs, and evaluation for LLM/Agent systems.

## Research Interests

- Multilingual LLMs and low-resource language expansion
- Reinforcement learning for LLM post-training
- LLM evaluation, robustness, and reliability
- Agent capability monitoring and benchmark construction
- Knowledge-enhanced generation and RAG systems

## Selected Work

- **Multilingual Encoder Knows More Than You Realize**  
  ACL 2025 Main, first author. A shared-weight pretraining framework for adapting multilingual encoders to extremely low-resource generation tasks.

- **Reinforcement Learning with Semantic Rewards Enables Low-Resource Language Expansion without Alignment Tax**  
  ACL 2026 Findings, first author. Reframes low-resource language expansion as semantic-space alignment and uses GRPO with semantic rewards.

- **InsightBenchMaker**  
  ACL 2026 Findings, co-first author. An automatic benchmark construction framework for data-analysis agents with executable verification.

- **DistractionIF**  
  Work in progress. Studies robustness against pseudo-instructions in reference text for RAG and Agent settings.

- **Agent-Potential Monitoring**  
  Work in progress. Monitors whether base and mid-training models already show ReAct-like interaction, structured action generation, and multi-turn tool-use potential.
